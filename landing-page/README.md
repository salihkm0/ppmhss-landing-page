# PPM HSS Landing Page

Official web portal and landing page for Panakkad Pookkoya Thangal Memorial Higher Secondary School (PPM HSS), Kottukkara, Kondotty, Kerala. Built with Next.js 16 (App Router), React 19, and Tailwind CSS.

## Features
- **Modern Responsive Design**: Clean educational branding with emerald theme (`#008744`).
- **Complete Institutional Pages**:
  - Home with Hero Slider, Highlights, and Quick Access
  - About Us: History, Vision & Mission, Leadership & Management, PTA
  - Academics: Streams (Science, Commerce, Humanities), Academic Calendar, Scholarships & Endowments, Faculty Directory
  - Campus Life: Labs, Library, Smart Classes, Sports, Kalolsavam, NSS, NCC, Scouts, SEED
  - Photo Gallery: Category-filtered gallery with interactive lightbox
  - Downloads & Circulars: Question papers, question banks, worksheets, circulars, application forms
  - Contact Us: Interactive Google Map, office contact lines, enquiry form
- **Admissions Portal**: Online admission enquiry application with real-time submission.
- **Alumni Network**: Alumni registration & testimonials.

## Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   npm start
   ```
